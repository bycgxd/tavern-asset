# 图片库

按《[图片命名规范](../图片命名规范.md)》重命名后的成品库。
源目录 `图集-中文命名/`、`环境/` **一个文件都没动**，这里全是副本。

**共 1511 张**（源 1633 张：112 张内容完全重复只留一份，10 张按你的要求不入库）。

---

## 目录

```
图片库/
├── 美雪/ 结衣/ 莉音/ 镜/ 雫/ 美月/          单人图片（立绘 + 单人 CG）
│   凉花/ 灯里/ 绵太/ 叶绘/ 光/
├── 多人CG/        两人及以上同框，集中存放
└── _索引.csv      1633 行，每张源图 → 新路径的对照
```

## 命名

| 类型 | 格式 | 例 |
|---|---|---|
| 单人立绘 | `角色_立绘_姿势_表情_服装_编号.png` | `美月_立绘_侧身回头_喜悦_黑色高领毛衣_005.png` |
| 单人 CG | `角色_CG_地点_画面内容_编号.png` | `镜_CG_仰躺抬腿手指抚弄下体_001.png` |
| 多人 CG | `甲与乙_CG_地点_画面内容_编号.png` | `美雪与结衣_CG_客厅_结衣坐被炉看书美雪端茶_001.png` |

- **编号** 按「角色＋姿势＋服装」（立绘）或「角色＋地点＋画面内容」（CG）分组，
  组内唯一；换表情、换差分**不重新从 001 开始**（规范第六节）。
- 地名一律取自角色卡 `地图位置` 条目，两边对得上。
- 多人组合按人物表固定顺序排（不会同时出现「美雪与结衣」和「结衣与美雪」）。

## 立绘的两套体系

游戏里立绘是两批素材，命名规律不同，本库都按规范统一了：

**族A**（11 人通用的动作立绘）原文件名是 `站立_v1_e3` 这种：

- 前缀 = **动作**：`站立 / 前倾 / 耕作 / 反击 / 疾冲 / 竞技 / 组合`
- `v` 后数字 = **服装**（每人一套编号，甲的第 1 套和乙的第 1 套不是同一件衣服）
- `e` 后数字 = **表情**（每人一套编号）

动作、服装、表情三张对照表（逐张看图核出来的）写在
`tools/build_image_library.py` 的 `ACTION` / `FASHION` / `EXPR` 里。

**族B**（母女三人另一套）原文件名是 `姿势1 / 换装2-A / 泳装` + 中文表情名，
表情名已按规范统一叫法（偷笑/高兴 → 喜悦，无奈 → 平静，表情G → 失落）。

### 表情字段的边界

`e` 后面的编号**只在「站立 / 疾冲」两个动作里才是同一套脸**
（这两套共用同一份表情图，已逐张比对确认）。所以：

| 动作 | 表情字段 | 原因 |
|---|---|---|
| 站立 / 疾冲 | 写了 | 编号含义一致，逐张核过 |
| 前倾 / 耕作 | 空 | 背对镜头，看不到脸 |
| 反击 / 竞技 / 组合 | 空 | 各自一套表情，编号含义与主表不同 |

另外两处被挪出表情字段的（按规范第二节，表情只放情绪）：

- 美月 `e2` `e3` —— 是「开口说话」的口型差分，记在 `差分描述` 里
- 美月 `e8` —— 是「OTOME帽墨镜口罩」的造型，归到 `服装`

词表收敛成 12 个：平静 · 微笑 · 喜悦 · 惊讶 · 紧张 · 害羞 · 嫌弃 · 困扰 · 失落 · 悲伤 · 不悦 · 闭目。
「微笑」= 睁眼嘴角上扬，「喜悦」= 闭眼弯笑，两者不再混用。

## 索引字段

`_索引.csv` 按规范第八节记录：

| 字段 | 说明 |
|---|---|
| 原始完整路径 | 回溯原文件 |
| 新相对路径 | 生成图片地址用 |
| 图片类型 | 立绘 / CG / 多人 / 未入库 / 重复 |
| 出场人物 | 单人或多人完整名单 |
| 地点 | 取不到就留空 |
| 画面内容 | 画面里实际在发生什么 |
| 表情 / 服装 | 立绘专有 |
| 差分描述 | 同组同名时靠什么区分，见下 |
| 核对状态 | 已确认 / 未入库 / 与上一行同图，未另存 |
| 备注 | 画面里有人但认不出是谁时写在这儿 |

## 同组 CG 的差分

同名（人物＋地点＋画面内容）的组有 **81 组**，全部填了 `差分描述`。分三类：

- **77 组** —— 逐像素比对后确认是**同一张图的两次导出**（差 1–2 像素的导出偏移 + 重压缩噪点，
  画面无实质区别）。索引里写「与同组另一张为同一画面的两次导出，画面无差别」。
  选图时任取一张即可。
- **4 组** —— 真有画面差异，逐张看图写明了差别：
  - `结衣_CG_床上_口交` —— 含入 / 拔出，睁眼 / 闭眼
  - `美雪_CG_紫泳衣抱少年头吸乳` —— 睁眼皱眉 / 闭眼笑
  - `美雪与莉音_CG_莉音开车美雪副驾少年后排交合` —— 三帧：并坐 / 少年伏上 / 仰躺被插入
  - `美雪_CG_客厅_三人围坐看电视` —— 蓝剪影趴桌上 / 坐在桌前
- **1 组** —— 单人立绘的口型差分（美月 `e2` `e3`），见上表。

## 多人名单核对

「描述里说了几个人、但只有一个角色名」的图逐张看过，结果写进覆盖表
`tools/image_library_overrides.json`：

- **认出来的**：改了 `出场人物`，挪进 `多人CG/`。例：`玄关-莉音-三人隔窗交谈`
  → `美雪与莉音_CG_玄关_三人隔窗交谈`（画面里背对的是美雪）。
- **认不出来的**：名字不动，在 `备注` 里写明「另有 N 人，未确认」。
  这类多半是游戏用**彩色剪影**代替的路人，认不出就不猜（规范第六节）。共 16 条。

## 没入库的 10 张

按你的要求，下面两类只留在源目录，不进图片库。索引里各留一行 `未入库`，
写明「原为『背景』／『待确认』」，源文件一个没动：

- **6 张纯背景**（群山日出、露营地篝火、夜晚温泉街景、空无一人）
- **4 张认不出人的**（`正面张腿亮出湿下体`、`黑白画风后入背影臀特写` 等）

要重新收进来，把 `tools/build_image_library.py` 里的 `DROP` 清空再跑一次即可。

## 怎么重建

```bash
py -3 tools/build_image_library.py
py -3 tools/verify_library.py
```

重建前先清空 `图片库/`（**`说明.md` 也在这个目录里，会被一起清掉，记得备份**）。

人工核对结果（名单覆盖、备注、差分）都在 `tools/image_library_overrides.json`，
改它不用改脚本。
